# ALRU8 · IP Monitor

Программа проверяет внешний IP через зарубежные сервисы, автоматически меняет часовой пояс по GeoIP и отключает интернет при обнаружении российского IP. В меню можно посмотреть результаты проверок, вручную отключить интернет или вернуть сохранённые настройки сети и исходный часовой пояс.

## Как запустить

Нужны Python 3.11+, curl и права администратора. Включи свой VPN и открой терминал в папке проекта.

**macOS / Linux:**

```sh
python3 vpn_guard.py
```

**Windows:**

```powershell
python vpn_guard.py
```

Программа сама запросит sudo/UAC. Режим выбирается в меню:

- **1 — Авто:** проверяет IP, меняет часовой пояс по GeoIP и отключает сеть при РФ или ошибке проверки.
- **2 — Проверка:** показывает IP, страну и timezone по сервисам, не меняя настройки.
- **3 — Отключить интернет:** блокирует пакеты и выключает сетевые адаптеры.
- **4 — Откатить всё:** возвращает исходный часовой пояс и сохранённые настройки сети.
- **0 — Выход.** Ctrl+C в мониторинге возвращает в меню.

После отключения сеть сама не включается — выбери **4**. Автозапуска нет.

## Что делает

Одновременно опрашивает 8 зарубежных сервисов: Cloudflare (два адреса), IP.SB, GeoJS, ipinfo.io, ipwho.is, Country.is и ifconfig.co. В авто-режиме первый ответ РФ вызывает блокировку IPv4/IPv6 и отключение Wi-Fi/Ethernet и других найденных физических адаптеров. Таймауты и ошибки отдельных сервисов не отключают интернет, если хотя бы один сервис подтвердил IP не из РФ; отключение происходит, только когда ни один сервис не подтвердил безопасный IP. Страна и часовой пояс выбираются по большинству ответов. Неожиданный возврат часового пояса тоже вызывает отключение.

На Mac используется PF и networksetup; на Linux — nftables, iproute2 и systemd/timedatectl; на Windows — WFP, PowerShell и tzutil. Для Linux установи зависимости: `sudo apt install python3 curl iproute2 nftables systemd`. Для Windows нужны Windows 10 1903+ / Windows 11 и 64-битный Python.

Если локальный прокси VPN не определился автоматически, укажи его в `configs/base.json`, например: `"proxy": "http://127.0.0.1:10809"`.

Также можно запустить `sh start.sh` на macOS/Linux или `powershell -File .\start.ps1` на Windows, если разрешён запуск PowerShell-скриптов.
